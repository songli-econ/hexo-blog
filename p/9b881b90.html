一些簡單的凸分析及其应用

时隔两年多，恢复更新了。这是一些簡單的凸分析的续篇。

目前只是草稿，会有很多错误。

Don’t follow my arguments for now, it’s just a draft of a draft.

在这篇中，我们想用一套统一的凸分析工具，把高微（一）中消费者理论和厂商理论里常见的对象——支出函数、间接效用函数、成本函数、利润函数——的性质“打包”推一遍，尽量不靠背诵，而是从共轭与支撑函数定理出发统一推出。

更具体一点，我们的目标是：

  • 从 concave / convex 指标函数（indicator functions）出发，引入 concave conjugate；
  • 把支出函数、成本函数、利润函数都写成某个指标函数的共轭；
  • 说明 Support Function Theorem、Conjugate Duality Theorem（Young–Fenchel）如何一锅端地产生 Shephard lemma、Hotelling lemma、Slutsky 矩阵等结论。

（间接效用函数稍微麻烦一些，这篇先主要讲支出 / 成本 / 利润。）

几个基本定义：指标函数与凹共轭

凹指标函数与凸指标函数

令 A⊂RmA\subset \mathbb{R}^mA⊂Rm 是一个凸集合。

**凹指标函数（concave indicator）**定义为

IA(x)={0,x∈A,−∞,x∉A. I_A(x) = \begin{cases} 0, & x\in A,\\ -\infty, & x\notin A. \end{cases} IA​(x)={0,−∞,​x∈A,x∈/A.​

也就是说，IAI_AIA​ 在集合内部“不给惩罚”（取 0），在集合外部施加无穷大的负惩罚（−∞-\infty−∞），使得任何 maximization / minimization 问题在有效域之外都变得劣得无法被选择。

对应的**凸指标函数（convex indicator）**定义为

δA(x)=−IA(x)={0,x∈A,+∞,x∉A. \delta_A(x) = - I_A(x) = \begin{cases} 0, & x\in A,\\ +\infty, & x\notin A. \end{cases} δA​(x)=−IA​(x)={0,+∞,​x∈A,x∈/A.​

注意这里的 IAI_AIA​ 与测度论中的 0/10/10/1 指示函数是不同的记号；我们在这个笔记中始终用上面的 extended real–valued 版本。

这一对定义基本上跟 Boyd / Border 的凸分析讲义完全一致。对凸集合 AAA，IAI_AIA​ 是凹函数、δA\delta_AδA​ 是凸函数。

凹共轭（concave conjugate）

在本文中，我们主要在“凹函数的世界”里工作。给定一个凹函数 f:E→R⋆f:E\to\mathbb{R}^{\star}f:E→R⋆（取值允许 ±∞\pm\infty±∞），其**凹共轭（concave conjugate）**定义为

f⋆(p):=inf⁡x∈E{p⋅x−f(x)}. f^{\star}(p) := \inf_{x\in E} \{p\cdot x - f(x)\}. f⋆(p):=x∈Einf​{p⋅x−f(x)}.

这是 Boyd / Border 的凹共轭约定：注意这里是“inf”，而不是更常见的“sup”（那对应的是凸共轭）。两者通过 f↔−ff \leftrightarrow -ff↔−f 的转换可以互相翻译。全文约定：f⋆f^{\star}f⋆ 一律指凹共轭（取 inf），凸共轭沿用 Fenchel 共轭的通行写法 f∗(p)=sup⁡x{p⋅x−f(x)}f^{*}(p)=\sup_{x}\{p\cdot x-f(x)\}f∗(p)=supx​{p⋅x−f(x)}（Border, Ec 181, Definition 16.1.1）。

若 f=IAf=I_Af=IA​ 是凹指标函数，则

  • 若 x∉Ax\notin Ax∈/A，则 f(x)=−∞f(x)=-\inftyf(x)=−∞，于是

    p⋅x−f(x)=p⋅x−(−∞)=+∞; p\cdot x - f(x) = p\cdot x - (-\infty) = +\infty; p⋅x−f(x)=p⋅x−(−∞)=+∞;

  • 若 x∈Ax\in Ax∈A，则 f(x)=0f(x)=0f(x)=0，于是

    p⋅x−f(x)=p⋅x. p\cdot x - f(x)=p\cdot x. p⋅x−f(x)=p⋅x.

因此对任何给定的 ppp，

IA⋆(p)=inf⁡x∈E{p⋅x−IA(x)}=inf⁡x∈Ap⋅x. I_A^{\star}(p) = \inf_{x\in E}\{p\cdot x - I_A(x)\} = \inf_{x\in A} p\cdot x. IA⋆​(p)=x∈Einf​{p⋅x−IA​(x)}=x∈Ainf​p⋅x.

我们把

f(p):=IA⋆(p)=inf⁡x∈Ap⋅x f(p) := I_A^{\star}(p) = \inf_{x\in A} p\cdot x f(p):=IA⋆​(p)=x∈Ainf​p⋅x

称为集合 AAA 的（凹）支撑函数（support function）。这是“由集合得到一个凹函数”的一个非常统一的方式。

经济学上你可以这样理解：

  • AAA 可以是某个上等偏好集（upper contour set），例如 U(uˉ)={x:u(x)≥uˉ}U(\bar u)=\{x: u(x)\ge \bar u\}U(uˉ)={x:u(x)≥uˉ}；
  • 也可以是某个上等产集（input requirement set）Z(q)={z:f(z)≥q}Z(q)=\{z: f(z)\ge q\}Z(q)={z:f(z)≥q}；
  • 在这两种情况下，inf⁡x∈Ap⋅x\inf_{x\in A} p\cdot xinfx∈A​p⋅x 就分别对应于“支出函数”和“成本函数”。

这一点下一节会更精确地写出来。

Conjugate Duality Theorem（Young–Fenchel）

这一节给出凹共轭版本的 Conjugate Duality Theorem，用的是 Boyd 的刻画。

Young–Fenchel 不等式与等式

给定适当、凹、上半连续的函数 f:E→R⋆f:E\to\mathbb{R}^{\star}f:E→R⋆，其凹共轭为

f⋆(p)=inf⁡y{p⋅y−f(y)}. f^{\star}(p)=\inf_{y} \{p\cdot y - f(y)\}. f⋆(p)=yinf​{p⋅y−f(y)}.

由定义立刻有：对任意 x,px,px,p，

f⋆(p)≤p⋅x−f(x)⇒f(x)+f⋆(p)≤p⋅x. f^{\star}(p) \le p\cdot x - f(x) \quad\Rightarrow\quad f(x) + f^{\star}(p) \le p\cdot x. f⋆(p)≤p⋅x−f(x)⇒f(x)+f⋆(p)≤p⋅x.

这就是Young–Fenchel 不等式。等号何时成立？

一方面，若 p∈∂⋆f(x)p\in\partial^{\star} f(x)p∈∂⋆f(x)，即 ppp 是在 xxx 处的 supergradient，则 supergradient 不等式

f(y)≤f(x)+p⋅(y−x)∀y f(y) \le f(x) + p\cdot (y-x)\quad\forall y f(y)≤f(x)+p⋅(y−x)∀y

等价于

p⋅x−f(x)≤p⋅y−f(y)∀y, p\cdot x - f(x) \le p\cdot y - f(y)\quad\forall y, p⋅x−f(x)≤p⋅y−f(y)∀y,

于是

f⋆(p)=inf⁡y{p⋅y−f(y)}=p⋅x−f(x), f^{\star}(p) = \inf_y \{p\cdot y - f(y)\} = p\cdot x - f(x), f⋆(p)=yinf​{p⋅y−f(y)}=p⋅x−f(x),

所以

f(x)+f⋆(p)=p⋅x. f(x)+f^{\star}(p)=p\cdot x. f(x)+f⋆(p)=p⋅x.

反之，若 f(x)+f⋆(p)=p⋅xf(x)+f^{\star}(p)=p\cdot xf(x)+f⋆(p)=p⋅x，再代回去可以验证 supergradient 不等式成立，从而 p∈∂⋆f(x)p\in\partial^{\star} f(x)p∈∂⋆f(x)。这就是 Boyd 所谓的 Young–Fenchel Equality。

Conjugate Duality Theorem

定理（Conjugate Duality Theorem，凹版本）
令 f:E→R⋆f:E\to\mathbb{R}^{\star}f:E→R⋆ 为适当、凹、上半连续函数。以下六个条件等价：

  1. xxx 使 p⋅y−f(y)p\cdot y - f(y)p⋅y−f(y) 在 y∈Ey\in Ey∈E 上取得最小：

    x∈arg⁡min⁡y{p⋅y−f(y)}. x\in\arg\min_{y} \{p\cdot y - f(y)\}. x∈argymin​{p⋅y−f(y)}.

  2. p∈∂⋆f(x)p\in\partial^{\star} f(x)p∈∂⋆f(x)，即 ppp 是 fff 在 xxx 的 supergradient。
  3. Young–Fenchel Equality 在 (x,p)(x,p)(x,p) 处成立：

    f(x)+f⋆(p)=p⋅x. f(x) + f^{\star}(p) = p\cdot x. f(x)+f⋆(p)=p⋅x.

  4. 对 f⋆⋆f^{\star\star}f⋆⋆ 也成立：

    f⋆⋆(x)+f⋆(p)=p⋅x. f^{\star\star}(x) + f^{\star}(p) = p\cdot x. f⋆⋆(x)+f⋆(p)=p⋅x.

  5. x∈∂⋆f⋆(p)x\in\partial^{\star} f^{\star}(p)x∈∂⋆f⋆(p)，即 xxx 是 f⋆f^{\star}f⋆ 在 ppp 的 supergradient。
  6. ppp 使 q⋅x−f⋆(q)q\cdot x - f^{\star}(q)q⋅x−f⋆(q) 在 qqq 上取得最小：

    p∈arg⁡min⁡q{q⋅x−f⋆(q)}. p\in\arg\min_{q} \{q\cdot x - f^{\star}(q)\}. p∈argqmin​{q⋅x−f⋆(q)}.

证明思路完全是 Boyd 讲义里的那套：利用 Young–Fenchel Equality 对 fff 与 f⋆f^{\star}f⋆ 各用一次，再用 f⋆⋆=ff^{\star\star}=ff⋆⋆=f（凹、上半连续保证）把 (3) 与 (4) 链接起来，即可得到 (1)–(6) 的相互等价。

在后面的 Support Function Theorem 里，第 (3) 条“x(p)=∂⋆f(p)x(p)=\partial^{\star} f(p)x(p)=∂⋆f(p)”以及第 (6) 条关于 Hessian 的结论，都要用到这个定理。

Support Function Theorem

现在回到最开始的设定。

令 A⊂RmA\subset\mathbb{R}^mA⊂Rm 为凸集合，IAI_AIA​ 为其凹指标函数，支撑函数

  3. 对效用的单调性
    这条虽然不直接来自支撑函数定理，但由上等偏好集的嵌套性立即推出：若 u2>u1u_2>u_1u2​>u1​，则 U(u2)⊂U(u1)U(u_2)\subset U(u_1)U(u2​)⊂U(u1​)，于是

    e(p,u2)=inf⁡x∈U(u2)p⋅x≥inf⁡x∈U(u1)p⋅x=e(p,u1), e(p,u_2)=\inf_{x\in U(u_2)} p\cdot x \ge \inf_{x\in U(u_1)} p\cdot x = e(p,u_1), e(p,u2​)=x∈U(u2​)inf​p⋅x≥x∈U(u1​)inf​p⋅x=e(p,u1​),

    且在局部非饱和偏好下这不等式是严格的。

  4. Hicksian demand 与 Shephard lemma
    令 Hicksian demand（支出最小化需求）为

    h(p,u)∈arg⁡min⁡x∈U(u)p⋅x. h(p,u)\in\arg\min_{x\in U(u)} p\cdot x. h(p,u)∈argx∈U(u)min​p⋅x.

    Support Function Theorem (3) 给出

    h(p,u)⊂∂p⋆e(p,u), h(p,u) \subset \partial^{\star}_p e(p,u), h(p,u)⊂∂p⋆​e(p,u),

    若最优解唯一且 eee 可微，则

    ∂e(p,u)∂pk=hk(p,u). \frac{\partial e(p,u)}{\partial p_k} = h_k(p,u). ∂pk​∂e(p,u)​=hk​(p,u).

    这就是 Shephard lemma 在消费者理论中的版本，与 Varian Ch.7 的陈述相同。

  5. Slutsky 矩阵（补偿需求版本）
    若 e(p,u)e(p,u)e(p,u) 在 ppp 上二阶可微，则 Support Function Theorem (6) 给出 Hessian Dp2e(p,u)D^2_p e(p,u)Dp2​e(p,u) 对称、负半定，并且乘以 ppp 为零向量。这个 Hessian 正是 Hicksian demand 的替代效应矩阵（纯替代效应），是 Slutsky 矩阵的“补偿版”，在 Varian 与更高阶教材中是标准结论。

综上，支出函数的所有经典性质（凹性、HD1、单调性、Shephard lemma、Slutsky 矩阵）都可以直接看作是 Support Function Theorem 的 corollaries。

2. 成本函数 c(w,q)c(w,q)c(w,q) 的性质

回忆：

c(w,q)=IZ(q)⋆(w),Z(q)={z≥0:f(z)≥q}. c(w,q) = I_{Z(q)}^{\star}(w), \quad Z(q)=\{z\ge 0: f(z)\ge q\}. c(w,q)=IZ(q)⋆​(w),Z(q)={z≥0:f(z)≥q}.

假设生产函数 fff 连续、凹且满足适当的单调性（投入越多不减产），则 Z(q)Z(q)Z(q) 闭、凸且在 R+m\mathbb{R}^m_+R+m​ 中向上闭合。

令 A=Z(q)A=Z(q)A=Z(q)，f(w)=c(w,q)f(w)=c(w,q)f(w)=c(w,q)，Support Function Theorem 直接给出 Cost Theorem 的大部分内容：

  1. 对要素价格的凹性与齐次性
    对每个 qqq，c(w,q)c(w,q)c(w,q) 对 www 凹、上半连续、HD1，并在其定义域内部连续。

  2. 对要素价格与产量的单调性
    由于 Z(q)Z(q)Z(q) 向上闭合，www 增大不会降低最小成本；qqq 增大使得 Z(q)Z(q)Z(q) 收缩，也不会降低成本。Boyd 在 Cost Theorem 中明确给出 c(w,q)c(w,q)c(w,q) 对 w,qw,qw,q 都是弱增加的。

  3. Shephard lemma（厂商版本）
    条件要素需求

    z(w,q)∈arg⁡min⁡z∈Z(q)w⋅z z(w,q)\in\arg\min_{z\in Z(q)} w\cdot z z(w,q)∈argz∈Z(q)min​w⋅z

    满足

    z(w,q)⊂∂w⋆c(w,q), z(w,q)\subset\partial^{\star}_w c(w,q), z(w,q)⊂∂w⋆​c(w,q),

    若解唯一且可微，则

    ∂c(w,q)∂wk=zk(w,q). \frac{\partial c(w,q)}{\partial w_k} = z_k(w,q). ∂wk​∂c(w,q)​=zk​(w,q).

    这是 Varian Ch.5 中 Shephard lemma 的标准形式。

  4. “要素需求定律”与 Hessian
    Support Function Theorem (4) 给出：若 zi∈z(wi,q)z_i\in z(w_i,q)zi​∈z(wi​,q)，则

    (z1−z0)⋅(w1−w0)≤0, (z_1 - z_0)\cdot (w_1 - w_0) \le 0, (z1​−z0​)⋅(w1​−w0​)≤0,

    即价格向量与要素需求向量的变化“反向”；这是条件要素需求的“定律”。若 ccc 在 www 上二阶可微，则 Hessian Dw2cD^2_w cDw2​c 对称、负半定，给出对称、负半定的“要素替代矩阵”。

3. 利润函数 π(p)\pi(p)π(p) 的性质

利润函数写法：

π(p)=sup⁡y∈Yp⋅y=(−IY)∗(p), \pi(p) = \sup_{y\in Y} p\cdot y = (-I_Y)^{*}(p), π(p)=y∈Ysup​p⋅y=(−IY​)∗(p),

这里 −IY-I_Y−IY​ 是 convex indicator，π\piπ 是它的凸共轭。

利用一般的 convex conjugate 性质（这一次是“凸世界”而不是“凹世界”）：

  1. π(p)\pi(p)π(p) 对 ppp 是凸函数，下半连续。
  2. 只要技术集合 YYY 不随价格 ppp 改变，π\piπ 对价格 ppp 正齐次一阶：对任意 α≥0\alpha\geq 0α≥0，π(αp)=απ(p)\pi(\alpha p)=\alpha\pi(p)π(αp)=απ(p)。这不需要 YYY 本身是锥；若 YYY 是锥，反而常会使利润函数只在某些价格下有限。
  3. 在“净产出”写法下，如果某些坐标对应投入（net output 为负），则 π\piπ 对这些坐标是单调非增，对产出价格坐标单调非减。
  4. 若能解出利润最大化最优净产出 y(p)y(p)y(p)，且解唯一、π\piπ 可微，则

    ∂π(p)∂pk=yk(p), \frac{\partial \pi(p)}{\partial p_k} = y_k(p), ∂pk​∂π(p)​=yk​(p),

    这就是 Hotelling lemma。

在教科书中（例如 Varian Ch.5 与 Ch.7），这些性质通常是一一证明的；在 Boyd / Border 的框架下，它们都是 convex conjugate 基础性质的 corollaries。

Recoverability：从支撑函数（值函数）恢复集合

Support Function Theorem (2) 给了一个非常重要的“可恢复性”结论：

  • 若 AAA 闭且凸，则

    f(p)=IA⋆(p)⇒f⋆(x)=IA(x), f(p) = I_A^{\star}(p) \quad\Rightarrow\quad f^{\star}(x) = I_A(x), f(p)=IA⋆​(p)⇒f⋆(x)=IA​(x),

    从而

    A={x:f⋆(x)=0}={x:p⋅x≥f(p) ∀p}. A = \{x: f^{\star}(x)=0\} = \{x: p\cdot x \ge f(p)\ \forall p\}. A={x:f⋆(x)=0}={x:p⋅x≥f(p) ∀p}.

对应到经济学：

  • 对消费者：给定支出函数 e(p,u)e(p,u)e(p,u)，可以通过 e(⋅,u)e(\cdot,u)e(⋅,u) 的共轭恢复上等偏好集 U(u)U(u)U(u)。这与 Varian 在 Ch.8 用支出函数解决 integrability 问题的思路是一致的（先从 demand 得到支出，再从支出恢复效用）。
  • 对厂商：给定成本函数 c(w,q)c(w,q)c(w,q)，可以通过共轭恢复上等产集 Z(q)Z(q)Z(q)，从而恢复生产技术的信息。

因此，支撑函数除了给出最优值，还把集合 AAA 整个恢复出来：A={x:f⋆(x)=0}A=\{x: f^{\star}(x)=0\}A={x:f⋆(x)=0}。
