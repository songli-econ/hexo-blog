可測最大值定理

預備

定義：可分空間

具有可數稠密子集的空間被稱為可分空間。例如實數系為可分空間，其可數稠密子集為有理數集。

定義：可度量化空間

給定一個拓撲空間，如果可以找到某個度量，使得該度量所引致的拓撲恰好就是該拓撲空間所配備的拓撲，則稱該拓撲空間為可度量化空間。

定義：上逆/強逆

給定一個對應 ϕ:S⇒X\phi:S\Rightarrow Xϕ:S⇒X，定義其上逆為 ϕu\phi^{u}ϕu 為對於任何 A⊂XA\subset XA⊂X，ϕu(A)={s∈S:ϕ(s)⊂A}\phi^{u}(A)=\left\{s\in S:\phi(s)\subset A\right\}ϕu(A)={s∈S:ϕ(s)⊂A}。

定義：下逆/弱逆

給定一個對應 ϕ:S⇒X\phi:S\Rightarrow Xϕ:S⇒X，定義其下逆為 ϕl\phi^{l}ϕl 為對於任何 A⊂XA\subset XA⊂X，ϕl(A)={s∈S:ϕ(s)∩A≠∅}\phi^{l}(A)=\left\{s\in S:\phi(s)\cap A\neq\emptyset\right\}ϕl(A)={s∈S:ϕ(s)∩A=∅}。

定義：弱可測對應

一個對應 ϕ:S⇒X\phi:S\Rightarrow Xϕ:S⇒X，如果對於任何開集 G⊂XG\subset XG⊂X，其弱逆 ϕl\phi^{l}ϕl 是可測的即 ϕl(G)∈Σ\phi^{l}(G)\in\Sigmaϕl(G)∈Σ，則稱這個對應是弱可測對應。

定義：乘積 σ\sigmaσ 代數

給定一族空間 XiX_{i}Xi​ 對於 i=1,...,ni=1,...,ni=1,...,n 及相應的 σ\sigmaσ 代數 Σi\Sigma_{i}Σi​，則乘積 σ\sigmaσ 代數 ⨂iΣi\bigotimes_{i}\Sigma_{i}⨂i​Σi​ 定義為由可測“矩形” ×iΣi\times_{i}\Sigma_{i}×i​Σi​ 生成的 σ\sigmaσ 代數。

例如，對於 X1=X2=RX_{1}=X_{2}=\mathbb{R}X1​=X2​=R 來説，其可測矩形真的就是矩形，例如取區間 (a1,b1)⊂X1(a_{1},b_{1})\subset X_{1}(a1​,b1​)⊂X1​ 和區間 (a2,b2)⊂X2(a_{2},b_{2})\subset X_{2}(a2​,b2​)⊂X2​，這個矩形就是以 a1,a2,b1,b2a_{1},a_{2},b_{1},b_{2}a1​,a2​,b1​,b2​ 為四個頂點的矩形，但由矩形們構成的集合族並不滿足 σ\sigmaσ 代數的要求，所以在 R2\mathbb{R}^{2}R2 上的乘積 σ\sigmaσ 代數是由這些矩形們生成的 σ\sigmaσ 代數而不是這些矩形們本身。

定義：Caratheodory 函數

給定可測空間 (S,Σ)(S,\Sigma)(S,Σ) 和拓撲空間 XXX，一個函數 f:S×X→Rf:S\times X\rightarrow\mathbb{R}f:S×X→R 是 Caratheodory 函數如果：

  • 對於任何 x∈Xx\in Xx∈X，函數 fx:=f(⋅,x):S→Rf^{x}:=f(\cdot,x):S\rightarrow\mathbb{R}fx:=f(⋅,x):S→R 是 (Σ,BR)(\Sigma,\mathscr{B}_{\mathbb{R}})(Σ,BR​) 可測的，其中 BR\mathscr{B}_{\mathbb{R}}BR​ 是 R\mathbb{R}R 上的 Borel σ\sigmaσ 代數。
  • 對於任何 s∈Ss\in Ss∈S，函數 fs:=f(s,⋅):x→Rf_{s}:=f(s,\cdot):x\rightarrow\mathbb{R}fs​:=f(s,⋅):x→R 是連續函數。

定義：聯合可測

給定三個可測空間 (S,Σ)(S,\Sigma)(S,Σ)、(X,BX)(X,\mathscr{B}_{X})(X,BX​) 和 (R,BR(\mathbb{R},\mathscr{B}_{\mathbb{R}}(R,BR​，如果函數 f:S×X→Rf:S\times X\rightarrow\mathbb{R}f:S×X→R 是 (Σ⨂BX,BR)(\Sigma\bigotimes\mathscr{B}_{X},\mathscr{B}_{\mathbb{R}})(Σ⨂BX​,BR​) 可測的，則稱函數 fff 是聯合可測的。

定義：可測選擇

給定一個對應 μ:S⇒X\mu:S\Rightarrow Xμ:S⇒X，如果存在某個單值可測函數 g:S→Xg:S\rightarrow Xg:S→X，使得對於每個 s∈Ss\in Ss∈S 都有 g(s)∈μ(s)g(s)\in\mu(s)g(s)∈μ(s)，則稱 ggg 是 μ\muμ 的一個可測選擇。

Filippov 隱函數定理

給定可分可度量化空間 XXX，給定可測空間 (S,Σ)(S,\Sigma)(S,Σ)。令 ϕ:S⇒X\phi:S\Rightarrow Xϕ:S⇒X 為有非空緊值得弱可測對應，及 f:S×X→Rf:S\times X\rightarrow\mathbb{R}f:S×X→R 為 Caratheodory 函數。令可測函數 π:S→R\pi:S\rightarrow\mathbb{R}π:S→R 為對於任何 s∈Ss\in Ss∈S 都存在某個 x∈ϕ(s)x\in\phi(s)x∈ϕ(s) 使得 π(s)=f(s,x)\pi(s)=f(s,x)π(s)=f(s,x)，則對應 γ:S⇒X\gamma:S\Rightarrow Xγ:S⇒X 定義為

γ(s)={x∈ϕ(s):f(s,x)=π(s)}\gamma(s)=\left\{x\in\phi(s):f(s,x)=\pi(s)\right\} γ(s)={x∈ϕ(s):f(s,x)=π(s)}

是可測對應。並且可測對應 γ\gammaγ 擁有可測選擇函數，即存在某個可測函數 ξ:S→X\xi:S\rightarrow Xξ:S→X 滿足 ξ(s)∈γ(s)\xi(s)\in\gamma(s)ξ(s)∈γ(s) 這個 ξ\xiξ 是 γ\gammaγ 之選擇的條件，以及繼承了 γ\gammaγ 本身的性質 pi(s)=f(s,ξ(s))pi(s)=f(s,\xi(s))pi(s)=f(s,ξ(s)) 對於每個 s∈Ss\in Ss∈S 都成立。

可測最大值定理

給定可分可度量化空間 XXX，給定可測空間 (S,Σ)(S,\Sigma)(S,Σ)。令 ϕ:S⇒X\phi:S\Rightarrow Xϕ:S⇒X 為有非空緊值得弱可測對應，及 f:S×X→Rf:S\times X\rightarrow\mathbb{R}f:S×X→R 為 Caratheodory 函數。定義值函數 m:S→Rm:S\rightarrow\mathbb{R}m:S→R 為

m(s):=max⁡x∈ϕ(s)f(s,x)m(s):=\max_{x\in\phi(s)}f(s,x) m(s):=x∈ϕ(s)max​f(s,x)

解對應 μ:S⇒X\mu:S\Rightarrow Xμ:S⇒X 為

μ(s):={x∈ϕ(s):f(s,x)=m(s)}\mu(s):=\left\{x\in\phi(s):f(s,x)=m(s)\right\} μ(s):={x∈ϕ(s):f(s,x)=m(s)}

則：

  • 值函數 mmm 為可測函數
  • 解對應 μ\muμ 有非空緊值
  • 解對應 μ\muμ 為可測對應，並具有可測選擇

可測最大值定理：證明

對每個固定的 sss，ϕ(s)\phi(s)ϕ(s) 是非空緊集，且 f(s,⋅)f(s,\cdot)f(s,⋅) 連續，因此 Weierstrass 定理保證最大值存在，值函數 mmm 是逐點定義良好的，解對應 μ\muμ 具有非空緊值。這裡還不能直接使用完整的 Berge 最大值定理，因為當前假設的是 ϕ\phiϕ 弱可測而非連續對應；可測性需要下面的 Castaing 表示與聯合可測性來推出。

根據引理 1，由假設 ϕ:S⇒X\phi:S\Rightarrow Xϕ:S⇒X 為有非空緊值的弱可測對應可知，存在可測選擇函數序列 {gn}\left\{g_{n}\right\}{gn​} 使得對於每個 s∈Ss\in Ss∈S 都有 ϕ(s)={g1(s),g2(s),...}ˉ\phi(s)=\bar{\left\{g_{1}(s),g_{2}(s),...\right\}}ϕ(s)={g1​(s),g2​(s),...}ˉ​。

據此定義向量值汎函 hn:S→S×Xh_{n}:S\rightarrow S\times Xhn​:S→S×X 為 hn(s):=(s,gn(s))h_{n}(s):=(s,g_{n}(s))hn​(s):=(s,gn​(s))，則對於每個 nnn 來説 hnh_{n}hn​ 都是 (Σ,Σ⨂BX)(\Sigma,\Sigma\bigotimes\mathscr{B}_{X})(Σ,Σ⨂BX​) 可測的。

由於 fff 是 Caratheodory 函數，根據引理2，fff 是 (Σ,BX)(\Sigma,\mathscr{B}_{X})(Σ,BX​) 聯合可測的，又 hnh_{n}hn​ 都 (Σ,Σ⨂BX)(\Sigma,\Sigma\bigotimes\mathscr{B}_{X})(Σ,Σ⨂BX​) 可測的，因此根據引理 3 其複合 f∘hnf\circ h_{n}f∘hn​ 是 Σ\SigmaΣ 可測的。又

m(s)=max⁡x∈ϕ(s)f(s,x)=sup⁡n∈Nf(s,gn(s))=sup⁡n∈Nf(hn(s))=sup⁡n∈N[f∘hn](s)\begin{aligned} m(s)=&\max_{x\in\phi(s)}f(s,x)\\ =&\sup_{n\in\mathbb{N}}f(s,g_{n}(s))\\ =&\sup_{n\in\mathbb{N}}f(h_{n}(s))\\ =&\sup_{n\in\mathbb{N}}\lbrack f\circ h_{n}\rbrack(s) \end{aligned}m(s)====​x∈ϕ(s)max​f(s,x)n∈Nsup​f(s,gn​(s))n∈Nsup​f(hn​(s))n∈Nsup​[f∘hn​](s)​

所以 m:S→Rm:S\rightarrow\mathbb{R}m:S→R 是 Σ\SigmaΣ 可測的。從而根據 Filippov 隱函數定理，解對應 μ:S⇒X\mu:S\Rightarrow Xμ:S⇒X 是可測對應，並且擁有可測選擇函數，即存在某個單值可測函數 ξ:S→X\xi:S\rightarrow Xξ:S→X 滿足對於每個 s∈Ss\in Ss∈S 都有 ξ(s)∈μ(s)\xi(s)\in\mu(s)ξ(s)∈μ(s)，當然 ξ\xiξ 也繼承了 μ\muμ 的性質，即對於每個 sss 來說 ξ(s)\xi(s)ξ(s) 都是原問題的最大解。
