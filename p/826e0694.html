連續時間的歐拉方程是如何得來的？
這篇筆記提供了一個簡易的推導，利用擾動方法得到了連續時間最優化問題的一階條件，即最大化原理。

用擾動法得到最優條件

考慮如下問題：

max⁡∫0Te−ρtu(Ct)dts.t.Kt˙=f(Kt)−Cte−rTKT≥0(1)\begin{aligned} &\max\int_{0}^{T}e^{-\rho t}u(C_{t})dt\\\\ &s.t.\\\\ &\dot{K_{t}}=f(K_{t})-C_{t}\\\\ &e^{-rT}K_{T}\geq 0 \end{aligned} \tag{1}​max∫0T​e−ρtu(Ct​)dts.t.Kt​˙​=f(Kt​)−Ct​e−rTKT​≥0​(1)

我們使用拉格朗日方法將其寫為：

L=∫0T[e−ρtu(Ct)+λt(f(Kt)−Ct−Kt˙)]dt+μe−rTKT(2)L=\int_{0}^{T}[e^{-\rho t}u(C_{t})+\lambda_{t}(f(K_{t})-C_{t}-\dot{K_{t}})]dt + \mu e^{-rT}K_{T}\tag{2} L=∫0T​[e−ρtu(Ct​)+λt​(f(Kt​)−Ct​−Kt​˙​)]dt+μe−rTKT​(2)

並記擾動為：

C(ϵ)=C⋆+p1ϵK(ϵ)=K⋆+p2ϵKT(ϵ)=KT⋆+ϵdKT(3)\begin{aligned}C(\epsilon)&=C^{\star}+p_{1}\epsilon\\ K(\epsilon)&=K^{\star}+p_{2}\epsilon\\ K_{T}(\epsilon)&=K_{T}^{\star}+\epsilon dK_{T} \end{aligned} \tag{3}C(ϵ)K(ϵ)KT​(ϵ)​=C⋆+p1​ϵ=K⋆+p2​ϵ=KT⋆​+ϵdKT​​(3)

如果C⋆C^{\star}C⋆、K⋆K^{\star}K⋆和KT⋆K_{T}^{\star}KT⋆​分別為最優值；
將擾動代入LLL得到L(ϵ)L(\epsilon)L(ϵ)，並將L(ϵ)L(\epsilon)L(ϵ)關於ϵ\epsilonϵ求導，可得必要條件：

∫0T[e−ρtu′(C⋆)p1+λt(f′(K⋆)p2−p1)+λt˙p2]dt−λTdKT+μe−rTdKT=0(4)\int_{0}^{T}[e^{-\rho t}u^{\prime}(C^{\star})p_{1}+\lambda_{t}(f^{\prime}(K^{\star})p_{2}-p_{1})+\dot{\lambda_{t}}p_{2}]dt-\lambda_{T} dK_{T}+\mu e^{-rT} dK_{T}=0\tag{4} ∫0T​[e−ρtu′(C⋆)p1​+λt​(f′(K⋆)p2​−p1​)+λt​˙​p2​]dt−λT​dKT​+μe−rTdKT​=0(4)

若要求當p1p_{1}p1​、p2p_{2}p2​為任意方向的偏離都有式（4）成立，則需有：

  1. e−ρtu′(C⋆)=λt,∀t(5)e^{-\rho t}u^{\prime}(C^{\star})=\lambda_{t},\forall t\tag{5} e−ρtu′(C⋆)=λt​,∀t(5)

  2. λtf′(K⋆)+λt˙=0,∀t(6)\lambda_{t}f^{\prime}(K^{\star})+\dot{\lambda_{t}}=0,\forall t\tag{6} λt​f′(K⋆)+λt​˙​=0,∀t(6)

  3. λT=μe−rT(7)\lambda_{T}=\mu e^{-rT}\tag{7} λT​=μe−rT(7)

定義γt=eρtλt\gamma_{t}=e^{\rho t}\lambda_{t}γt​=eρtλt​，並相應地改寫λt˙=−ρe−ρtγt+e−ρtγt˙\dot{\lambda_{t}}=-\rho e^{-\rho t}\gamma_{t}+e^{-\rho t}\dot{\gamma_{t}}λt​˙​=−ρe−ρtγt​+e−ρtγt​˙​即可得到常見的一階條件:

  1. u′(C⋆)=γt,∀t(5’)u^{\prime}(C^{\star})=\gamma_{t},\forall t\tag{5'} u′(C⋆)=γt​,∀t(5’)

  2. γtf′(K⋆)+γt˙=ργt,∀t(6’)\gamma_{t}f^{\prime}(K^{\star})+\dot{\gamma_{t}}=\rho \gamma_{t},\forall t\tag{6'} γt​f′(K⋆)+γt​˙​=ργt​,∀t(6’)

  3. γT=μe−(r−ρ)T(7’)\gamma_{T}=\mu e^{-(r-\rho)T}\tag{7'} γT​=μe−(r−ρ)T(7’)

並且，將式（7）與式（1）中原問題的非負約束相結合，互補鬆弛條件為μe−rTKT=0\mu e^{-rT}K_{T}=0μe−rTKT​=0，而λT=μe−rT\lambda_{T}=\mu e^{-rT}λT​=μe−rT，因此有λTKT=0\lambda_{T}K_{T}=0λT​KT​=0。又因λT=e−ρTγT\lambda_{T}=e^{-\rho T}\gamma_{T}λT​=e−ρTγT​，所以 current-value 寫法下的終端條件是

γTe−ρTKT=0,\gamma_{T}e^{-\rho T}K_{T}=0, γT​e−ρTKT​=0,

當無窮期 T→∞T\rightarrow\inftyT→∞ 時即為lim⁡t→∞γte−ρtKt=0\lim_{t\rightarrow\infty}\gamma_{t}e^{-\rho t}K_{t}=0limt→∞​γt​e−ρtKt​=0。

Hamiltonian

我們在宏觀領域裡經常會見到“Present value Hamiltonian”和“Current value Hamiltonian”的說法，對於中文讀者來說，這兩個詞不都是“現在”的意思嗎？有什麼區別？
區別就是：
present在這裡指的是規劃期，常是第0期；
而current在這裡指的是第t期。
以這種方式理解：
KKK的運動方程表示的是第t期的瞬時變化；
current value單期效用函數就是按第t期衡量的uc=u(Ct)u_{c}=u(C_{t})uc​=u(Ct​)；
把current單期效用函數前乘個e−ρte^{-\rho t}e−ρt就變成了摺算成第0期的present value單期效用函數up=e−ρtu(Ct)u_{p}=e^{-\rho t}u(C_{t})up​=e−ρtu(Ct​)。
因此有：

Hp=e−ρtHcHc=eρt[up(C(t))+λt(f(Kt)−Ct)]=uc+λteρt(f(Kt)−Ct)\begin{aligned} H_{p}&=e^{-\rho t}H_{c}\\ H_{c}&=e^{\rho t}[u_{p}(C(t))+\lambda_{t}(f(K_{t})-C_{t})]\\ &=u_{c}+\lambda_{t}e^{\rho t}(f(K_{t})-C_{t})\\ \end{aligned}Hp​Hc​​=e−ρtHc​=eρt[up​(C(t))+λt​(f(Kt​)−Ct​)]=uc​+λt​eρt(f(Kt​)−Ct​)​

（經濟含義解釋待補充）

便於記憶：如果我們將e−ρte^{-\rho t}e−ρt稱為折現，那麼present value和current value的漢彌爾頓函數的區別在於：如果折的是目標(biao)函數，那麼就稱為present value；如果折的是乘(Cheng)子，那麼就稱為current value。但由於乘子是可以改寫的，所以有時候並不能看出乘子是否被折現了，那麼判斷標準也可以記為：如果原目標函數中是否折現的，那麼當漢彌爾頓函數中的當期瞬時效用函數帶著折現項，則為present value；如果不帶，則為current value。

原問題是個無窮期從 0 到 ∞\infty∞ 的問題，漢彌爾頓函數中的問題是某個/每個 ttt 時點的問題。這是一種極大的簡化。

Dorfmanian

D=e−ρtu(C(t))+γ(t)K˙(t)+γ˙(t)K(t)=e−ρtu(C(t))+γ(t)(f(Kt)−Ct)+γ˙(t)K(t)\begin{aligned}D&=e^{-\rho t}u(C(t))+\gamma(t)\dot{K}(t)+\dot{\gamma}(t)K(t)\\ &=e^{-\rho t}u(C(t))+\gamma(t)(f(K_{t})-C_{t})+\dot{\gamma}(t)K(t) \end{aligned}D​=e−ρtu(C(t))+γ(t)K˙(t)+γ˙​(t)K(t)=e−ρtu(C(t))+γ(t)(f(Kt​)−Ct​)+γ˙​(t)K(t)​

將其關於 C(t)C(t)C(t) 和 K(t)K(t)K(t) 求導，得到一階條件

e−ρtu′(C(t))=γ(t)γ(t)f′(Kt)=−γ˙(t)\begin{aligned} e^{-\rho t}u^{\prime}(C(t))=&\gamma(t)\\ \gamma(t)f^{\prime}(K_{t})&=-\dot{\gamma}(t)\\ \end{aligned}e−ρtu′(C(t))=γ(t)f′(Kt​)​γ(t)=−γ˙​(t)​

將歐拉方程

e−ρtu′(C(t))=γ(t)e^{-\rho t}u^{\prime}(C(t))=\gamma(t) e−ρtu′(C(t))=γ(t)

關於 ttt 求導

−ρe−ρtu′(C(t))+e−ρtu′′(C(t))C˙(t)=γ˙(t)-\rho e^{-\rho t}u^{\prime}(C(t))+e^{-\rho t}u^{\prime\prime}(C(t))\dot{C}(t)=\dot{\gamma}(t) −ρe−ρtu′(C(t))+e−ρtu′′(C(t))C˙(t)=γ˙​(t)

代入

γ(t)f′(Kt)=−γ˙(t)\gamma(t)f^{\prime}(K_{t})=-\dot{\gamma}(t) γ(t)f′(Kt​)=−γ˙​(t)

得到

−γ(t)f′(Kt)=−ρe−ρtu′(C(t))+e−ρtu′′(C(t))C˙(t)-\gamma(t)f^{\prime}(K_{t})=-\rho e^{-\rho t}u^{\prime}(C(t))+e^{-\rho t}u^{\prime\prime}(C(t))\dot{C}(t) −γ(t)f′(Kt​)=−ρe−ρtu′(C(t))+e−ρtu′′(C(t))C˙(t)

代入歐拉方程，得到

−e−ρtu′(C(t))f′(Kt)=−ρe−ρtu′(C(t))+e−ρtu′′(C(t))C˙(t)-e^{-\rho t}u^{\prime}(C(t))f^{\prime}(K_{t})=-\rho e^{-\rho t}u^{\prime}(C(t))+e^{-\rho t}u^{\prime\prime}(C(t))\dot{C}(t) −e−ρtu′(C(t))f′(Kt​)=−ρe−ρtu′(C(t))+e−ρtu′′(C(t))C˙(t)

整理

−u′(C(t))f′(Kt)=−ρu′(C(t))+u′′(C(t))C˙(t)-u^{\prime}(C(t))f^{\prime}(K_{t})=-\rho u^{\prime}(C(t))+u^{\prime\prime}(C(t))\dot{C}(t) −u′(C(t))f′(Kt​)=−ρu′(C(t))+u′′(C(t))C˙(t)

再整理

−f′(Kt)=−ρ+u′′(C(t))u′(C(t))C˙(t)-f^{\prime}(K_{t})=-\rho+\frac{u^{\prime\prime}(C(t))}{u^{\prime}(C(t))}\dot{C}(t) −f′(Kt​)=−ρ+u′(C(t))u′′(C(t))​C˙(t)

定義

σ(C(t))=−C(t)u′′(C(t))u′(C(t))\sigma(C(t))=-\frac{C(t)u^{\prime\prime}(C(t))}{u^{\prime}(C(t))} σ(C(t))=−u′(C(t))C(t)u′′(C(t))​

得到

f′(Kt)=ρ−C(t)u′′(C(t))u′(C(t))C˙(t)C(t)=ρ+σ(C(t))C˙(t)C(t)\begin{aligned}f^{\prime}(K_{t})&=\rho-\frac{C(t)u^{\prime\prime}(C(t))}{u^{\prime}(C(t))}\frac{\dot{C}(t)}{C(t)}\\ &=\rho+\sigma(C(t))\frac{\dot{C}(t)}{C(t)} \end{aligned}f′(Kt​)​=ρ−u′(C(t))C(t)u′′(C(t))​C(t)C˙(t)​=ρ+σ(C(t))C(t)C˙(t)​​

整理，得到消費的動態方程

C˙(t)C(t)=1σ(C(t))[f′(Kt)−ρ]\frac{\dot{C}(t)}{C(t)}=\frac{1}{\sigma(C(t))}[f^{\prime}(K_{t})-\rho] C(t)C˙(t)​=σ(C(t))1​[f′(Kt​)−ρ]

即，Dorfmanian 對於動態變量 K(t)K(t)K(t) 需要補充一項 γ˙(t)K(t)\dot{\gamma}(t)K(t)γ˙​(t)K(t)，隨後即可應用常見的“求導並令其為零”操作而無需記憶相關的正負 ρ\rhoρ 項。
